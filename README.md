Репозиторий содержит программную реализацию автоматизированного инструмента для сбора, документирования и защищенной передачи предложений сотрудников по оптимизации бизнес-процессов (ППУ). 

## Описание предметной области

В современных корпоративных системах управления качеством и непрерывным улучшением критически важны скорость сбора инициатив и защита конфиденциальной информации. Традиционные методы сбора ППУ (бумажные носители, незащищенные электронные письма) подвержены рискам потери данных и требуют значительных временных затрат на консолидацию.

Данное решение реализует сквозной автоматизированный пайплайн:
1. **Структурированный сбор:** Сотрудник заполняет форму ППУ через диалоговый интерфейс Telegram с возможностью прикрепления фотоматериалов («до» и «после» внедрения улучшения).
2. **Автоматическая генерация отчетности:** Система автоматически формирует стандартизированный Word-документ на основе шаблона и обновляет сводный Excel-реестр предложений.
3. **Защищенная передача:** Итоговые файлы упаковываются в архив с применением шифрования AES-256 и передаются администратору, после чего временные локальные файлы безопасно удаляются.

## Технологический стек

- **Язык программирования:** Python 3.11+
- **Фреймворк для Telegram-ботов:** `aiogram` (v2.x)
- **Генерация документов:** `docxtpl`, `python-docx`
- **Обработка табличных данных:** `openpyxl`
- **Криптография и архивация:** `pyzipper` (AES-256)
- **Управление конфигурацией:** `python-dotenv`
- **Хранение данных:** Локальная файловая система (шаблоны, временные изображения, реестр)
